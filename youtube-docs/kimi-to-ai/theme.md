# YouTubeチャンネル設定資料

## チャンネル概要

### チャンネル名
**あかるみょチャンネル**

### コンセプト
**現実では絶対不可能な超常現象・魔法・異世界体験を3人組が本気で挑戦する、完全にぶっ飛んだエンターテイメントチャンネル**

AIで生成されたキャラクターだからこそ実現できる、物理法則を無視した超非現実的なコンテンツを展開。視聴者には「もしも現実でこんなことができたら...」という夢と驚きを提供する。

### ターゲット層
- 10代〜40代前半
- ファンタジー・アニメ・ゲーム好き
- 非日常・超常現象コンテンツファン
- AI生成コンテンツに興味がある層
- 「現実では不可能なこと」を見たい視聴者

## キャラクター関係性

### 背景設定
- **出身**: 全員群馬県出身の幼馴染
- **現在**: 東京の秘密基地でルームシェア中（異次元空間に接続可能）
- **関係性**: 気心知れた仲間、お互いの超常能力を理解し合っている
- **特殊設定**: 3人揃うと更に強力な合体技が使える

### 動画内での役割分担
- **Akane**: 企画の説明、進行管理、視聴者への呼びかけ、魔法陣の準備
- **Harurun**: 実際の行動・実験の実行、危険なチャレンジ担当、体力系の超常現象実演
- **Myoko**: 技術的なサポート、結果の分析・解説、冷静なツッコミ、召喚術の実行

---

## コンテンツの方向性

### 動画ジャンル
1. **魔法・召喚系**: ドラゴン召喚、異世界への扉開け、魔法実験
2. **超能力チャレンジ系**: 空中浮遊、瞬間移動、時間停止チャレンジ
3. **異世界探訪系**: 別次元旅行、過去未来への移動、パラレルワールド体験
4. **超常現象検証系**: 都市伝説の真相究明、UMA捕獲、心霊現象の科学的解析
5. **非現実料理系**: 魔法の食材で料理、食べると能力が上がる料理作り
6. **群馬ファンタジー系**: 群馬の伝説・神話を現実で再現

### 動画の特徴
- 群馬の方言を自然に使用（非現実世界でも故郷愛は変わらず）
- 3人の超常能力がぶつかり合う壮大なコメディ要素
- 魔法と科学を融合させた独自の世界観
- 「現実では絶対不可能」だからこそのスケールの大きさ
- 視聴者を異世界に連れて行くような没入感

## ビジュアル・ブランディング

### カラーパレット
- **Primary**: RGB三原色（赤・緑・青）+ 魔法的なオーラエフェクト
- **Secondary**: 異次元空間をイメージした虹色グラデーション
- **Accent**: 金色（魔法陣）、銀色（召喚エフェクト）

### ロゴ・デザイン要素
- 上毛三山のシルエット + 魔法陣
- 3人のイニシャル（A・H・M）を魔法文字風にデザイン
- 群馬県の形 + 異次元ポータルのエフェクト
- ドラゴンや幻獣のシルエット

## 制作ガイドライン

### キャラクターの一貫性
- 各キャラクターの口癖や性格を必ず反映
- テーマカラーを衣装や魔法エフェクトで表現
- 群馬出身の設定を非現実世界でも自然に盛り込む
- 超常能力の設定を動画ごとに一貫して使用
- 魔法や超能力を使っても3人の基本的な関係性は変わらず

### 動画の品質基準
- 8秒以内のシーン構成
- 200文字以内のセリフ
- ローマ字表記ルールの遵守
- 4K画質での制作
- VFX・魔法エフェクトを積極的に使用
- 「現実では絶対不可能」な映像表現を追求

### AI生成コンテンツの強み活用
- 物理法則を無視した映像表現
- 実写では不可能なスケールの演出
- 危険すぎて現実では撮影できないシーンの再現
- 無限の想像力を映像化
- コスト制約なしの壮大な世界観構築
