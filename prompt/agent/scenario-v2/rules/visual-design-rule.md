# ビジュアルデザインルール

## 基本設計思想
YouTube動画の各シーンに最適化された画像生成プロンプトを作成し、視聴者の関心維持と情報理解を視覚的に支援する。

## プロンプト生成原則

### 1. 構造化アプローチ
```
[主要被写体] + [アクション/状態] + [環境/背景] + [スタイル指定] + [ムード/照明] + [構図指定] + [品質指定]
```

### 2. 一貫性維持
- 動画全体を通したビジュアルスタイル統一
- カラーパレットの調和
- ブランディング要素の継続性

### 3. YouTube最適化
- アスペクト比16:9への対応
- サムネイル効果も考慮した魅力度
- モバイル視聴での視認性確保

## スタイル分類システム

### 写真風 (realistic photography)
**適用場面**:
- 動物の実際の行動や生態
- 自然環境や風景
- リアリティが重要な説明

**プロンプト要素**:
- "realistic photography"
- "natural lighting"
- "high resolution"
- "professional quality"

### イラスト風 (illustration style)
**適用場面**:
- 親しみやすさ重視のコンテンツ
- 概念や抽象的説明
- 若年層ターゲットコンテンツ

**プロンプト要素**:
- "cute illustration"
- "cartoon style"
- "colorful"
- "friendly design"

### 図解風 (infographic style)
**適用場面**:
- 数値データや比較
- 複雑な仕組みの説明
- 教育的コンテンツ

**プロンプト要素**:
- "infographic design"
- "clean layout"
- "educational style"
- "clear visualization"

## 構図設計基準

### アップショット (close-up)
- 表情や細部の表現重視
- 感情的インパクト最大化
- 視聴者との距離感短縮

### ミディアムショット (medium shot)
- バランス重視の汎用構図
- 被写体と環境の両立
- 安定感のある表現

### ワイドショット (wide shot)
- 環境や状況の全体表現
- スケール感の演出
- 開放感や壮大さ表現

### 俯瞰ショット (aerial view)
- 特別な視点での印象創出
- 全体像の把握支援
- ドラマチック効果

## ムード設定指針

### 明るい (bright)
- ポジティブなコンテンツ
- 楽しい雑学や可愛い動物
- 視聴者の気分向上狙い

### 落ち着いた (calm)
- 知的なコンテンツ
- 深い理解を促す説明
- 信頼感の醸成

### ドラマチック (dramatic)
- 驚きや衝撃的事実
- 注意喚起の必要な場面
- インパクト重視シーン

### 可愛い (cute)
- 動物の愛らしい行動
- ほっこり系コンテンツ
- 親近感の醸成

## シーン別ビジュアル戦略

### intro専用設計
- **目標**: 動画への関心最大化
- **要素**: インパクト + 親しみやすさ
- **構図**: ワイド〜ミディアム推奨
- **ムード**: 明るい、ドラマチック

### subtitle専用設計
- **目標**: 次への期待感醸成
- **要素**: シンプル + 効果的
- **構図**: ミディアム中心
- **ムード**: コンテンツ内容に応じて調整

### content専用設計
- **目標**: 情報の視覚的補強
- **要素**: 内容理解支援 + 魅力化
- **構図**: 内容に最適化
- **ムード**: トピックの性質反映

### outro専用設計
- **目標**: 満足感 + 継続意欲
- **要素**: 温かみ + 安定感
- **構図**: ミディアム〜ワイド
- **ムード**: 明るい、落ち着いた

## 品質基準

### 技術的品質
- 4K解像度対応
- プロフェッショナルクオリティ
- 生成可能性の確保

### 内容整合性
- caption_textとの完全一致
- 情報の正確な視覚化
- 誤解を招かない表現

### 視聴者体験
- ターゲット層への訴求力
- 継続視聴への貢献
- SNS共有価値の創出

## 禁止事項

### 内容逸脱
- caption_textにない要素の追加
- 事実と異なる視覚表現
- 文脈に合わない演出

### 品質劣化
- 低解像度指定
- 不鮮明な表現指示
- 生成困難な複雑すぎる指示

### ブランド毀損
- 不適切な表現
- 視聴者層に不適合な内容
- チャンネルイメージとの不整合

## プロンプト最適化技法

### 効果的キーワード
- "ultra detailed", "high quality"
- "professional lighting"
- "cinematic composition"
- "vibrant colors"

### スタイル統一語彙
- 動画全体で一貫した修飾語使用
- ブランドカラーの指定
- 特徴的な表現要素の継続

### 生成成功率向上
- 具体的で明確な指示
- 矛盾しない要素組み合わせ
- 実現可能性を考慮した構成
