### 検索結果報告フォーマット
以下のマークダウン形式で検索結果の報告を行うこと
```markdown
# 検索結果報告: [調査テーマ]

## 実行した検索
1. "[クエリ]" - [検索の目的]
2. "[クエリ]" - [検索の目的]
3. "[クエリ]" - [検索の目的]
...

## 収集した情報

### [カテゴリ1: 基本情報]
- **[項目名]**: [詳細な情報・数値データ・出典]
- **[項目名]**: [詳細な情報・数値データ・出典]

### [カテゴリ2: 科学的データ]
- **研究情報**: [研究者名・機関・発表年・内容]
- **数値データ**: [具体的な数値・単位・測定条件・出典]

### [カテゴリ3: エンタメ要素]
- **面白い行動**: [視聴者が驚く行動・特徴・習性]
- **意外性**: [一般認識との違い・驚きの内容・新発見]
- **危険性**: [可愛い見た目とは裏腹な危険な一面・問題行動]
- **珍しい事実**: [最近の発見・レアな事例・研究で判明した新事実]

### [カテゴリ4: 具体的エピソード]
- **実際の事例**: [場所・時期・詳細な状況・関係者]
- **研究事例**: [研究機関・研究者・発見の経緯・詳細]
- **実生活事例**: [日常生活・体験談・具体的な影響]

### [カテゴリ5: 視覚的情報]
- **映像映えする要素**: [具体的な現象・プロセス・実演可能な内容]
- **視覚的特徴**: [意外な部分・面白い特徴・視覚的インパクト]

## 情報の信頼性評価
- **高信頼**: [学術論文・公式機関・専門研究者・政府機関の情報]
- **中信頼**: [専門サイト・業界団体・専門家の公式情報]
- **要確認**: [一般サイト・未確認情報・個人ブログ]

## 追加調査の提案
- [不足している情報や深掘りが必要な項目]
- [矛盾する情報の確認が必要な項目]
```
