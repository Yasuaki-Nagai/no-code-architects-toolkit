### 検索実行ルール
#### 効果的なクエリ作成ルール
##### **DO（推奨）**
- **1つのクエリ = 1つの概念**に絞る
- **複数言語検索**：
   - 以下の言語での検索を推奨
      - 日本語
      - 英語
- **キーワードは3-5個まで**に制限
- **段階的に詳細化**：検索戦略で定められた順で検索
- **類似語・同義語**を使って複数回検索

##### **DON'T（避けるべき）**
- **禁止: 長すぎるクエリ**：6語以上のクエリは分割して検索
- **禁止: 言語混在**：「sea otter ラッコ」のような混在は禁止
- **禁止: 過度な特定化**：最初から特定の論文や年度を指定しない
- **禁止: 複数概念の混在**：「密度 and 行動 and 研究」のような複合は分割

#### 検索戦略（推奨→基本→詳細→超詳細→補完）
##### 事前準備された静的クエリでの検索
1. **推奨検索**:
   - 推奨検索の指示がある場合、まず最初はその指示に従って情報を収集する
   - 推奨検索の指示がない場合、スキップして基本検索から始める
2. **基本検索**: 基礎的なキーワードで全体像を把握

##### 動的クエリでの検索
以降の検索では、推奨検索と基本検索結果を分析して台本候補としてふさわしい要素を抽出し、深掘り検索を実施する。そのためのクエリは検索結果(推奨検索から補完検索まで)をもとに動的に決定する。
3. **詳細検索**: 具体的データ・数値・研究結果を収集
4. **超詳細検索**: エンタメ要素に特化した調査
   - 面白い行動・特徴
   - 意外性・驚きの事実
   - 危険性・問題行動
   - 珍しい発見・最新研究
5. **補完検索**: 不足情報を埋める追加検索

#### 検索クエリ例

**変数の説明**
これから説明する検索クエリの例で使用している変数については以下のように解釈すること
- `<トピック>`: 日本語での検索対象のトピックを入れるための変数であることを示している
   - 例: トピックが`ラッコ`であれば`<トピック>`は`ラッコ`に置換する
- `<topic>`: 英語での検索対象のトピックを入れるための変数であることを示している
   - 例: トピックが`ラッコ`であれば`<topic>`は`sea otter`に置換する

##### **良い例（推奨）**
以下はあくまで例であり、トピックと組み合わせるクエリは入力情報の`ジャンル`、`台本テーマ`、および`チャンネルポリシー`に沿った内容にする。
```
# 基礎情報（日本語）
- "<トピック> 基本情報"
- "<トピック> 特徴"
- "<トピック> 仕組み"

# 基礎情報（英語）
- "<topic> basic information"
- "<topic> characteristics"
- "<topic> mechanism"

# 具体的データ（詳細段階）
- "<トピック> 数値 データ"
- "<topic> statistics research"
- "<トピック> 測定 結果"

# エンタメ要素（超詳細段階）
- "<トピック> 面白い 事実"
- "<topic> surprising facts"
- "<トピック> 意外 発見"
- "<topic> unusual phenomena"
- "<トピック> 珍しい 現象"
```

##### **悪い例（避けるべき）**
```
禁止:
   - クエリ: "<topic> detailed mechanism comprehensive analysis <トピック> 詳細"
   - 禁止理由: 複数言語が混在しておりクエリ数が過剰
禁止:
   - クエリ: "phenomenon statistics measurement data analysis 現象 統計"
   - 禁止理由: 複数言語が混在しておりクエリ数が過剰
禁止:
   - クエリ: "<トピック> 基本 特徴 仕組み データ 事例 研究"
   - 禁止理由: クエリ数が過剰
```

### 情報収集の重点事項
#### 必須収集情報
1. **科学的根拠**
   - 研究者名・研究機関名
   - 観察や統計などの記録・数値データ
   - 学術的な説明・メカニズム
   - 研究の出典情報

2. **エンタメ要素**
   - **面白い行動**: 視聴者が「へぇ〜」と驚く行動や特徴
   - **意外性**: 一般的なイメージとは異なる驚きの事実
   - **危険性・問題**: 可愛い見た目とは裏腹な危険な一面
   - **珍しい発見**: 最近発見された新事実や研究結果

3. **具体的エピソード**
   - 実際の事例（面白さや驚きで視聴者ウケが良いもの優先）
   - 研究中の発見・失敗例・予想外の出来事
   - 実生活での興味深い事例・体験談

4. **視覚的情報**
   - 行動の詳細な様子（映像映えする内容）
   - 見た目の特徴（意外な部分・面白い部分）
   - 実演可能なデモンストレーションの描写

#### 情報の品質基準
- **具体性**:
   - 例: 「研究で確認されている」ではなく「○○大学の△△博士の研究で確認」
- **数値性**:
   - 例:「多い」ではなく「1日○○時間」「○○%の確率」
- **詳細性**:
   - 例:「問題がある」ではなく「具体的にどんな問題がどんな状況で発生するか」
- **信頼性**:
   - 例:複数の情報源で裏付けを取る
