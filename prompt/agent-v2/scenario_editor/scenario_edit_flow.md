### 台本修正の進め方

#### 1. 評価結果の詳細分析
- Critical Issues の特定と優先順位付け
- Major/Minor Issues の整理
- 改善提案の実行可能性評価
- 全体的な修正方針の決定

#### 2. 構造的問題の修正
- サブタイトル配置の調整（最後の雑学にはサブタイトルなし）
- 形式一貫性の確保（ランキング/ナンバリング形式）
- scene_type の適切な設定
- 文字数制限の遵守

#### 3. 内容・表現の改善
- ソース制限の厳守確認
- エンターテイメント性の向上
- カジュアルで親しみやすい表現への変更
- 感情表現の強化（驚き、共感、面白さ）

#### 4. 文字数最適化の実行
- 全体文字数のチェックと調整(文字数の増減/オブジェクト自体の増減)
- scene_typeごとのオブジェクトの文字数超過のチェックと調整(文字数の増減/オブジェクト自体の増減/オブジェクトの分割)
- 調整後の表現最適化
- 文節ごとの適切な改行
- 視認性の最大化

#### 5. 全体調整
- 流れの自然さの確保
- テーマ一貫性の維持
- ターゲット層への適合性確認
- フック戦略の効果的実装

修正完了後は、レビュアーが指摘した全ての問題点が解決され、より魅力的で質の高い台本になることを目指してください。

### 修正例

#### Critical Issue対応例
**問題**: 文字数超過（content: 35文字）
**修正前**: `["実はコアラの赤ちゃんは生まれてすぐお母さんのうんちを食べるんだよ"]`
**修正後**: 
```json
[
  {"scene_type": "content", "caption_text": ["実は", "コアラの赤ちゃんは"]},
  {"scene_type": "content", "caption_text": ["生まれてすぐ", "あるものを", "食べる"]},
  {"scene_type": "content", "caption_text": ["それは", "お母さんの"]},
  {"scene_type": "content", "caption_text": ["パップと", "呼ばれる", "うんちなんだ"]}
]
```

#### Entertainment Enhancement例
**問題**: 硬い表現、感情表現不足
**修正前**: `["対向する指が2本あり強力なグリップを実現"]`
**修正後**: `["なんと", "親指が", "2本もあって", "まるで", "職人みたい"]`

### 修正後の確認事項
- **ルール完全遵守**:
  - 全ての基本ルールがクリアされているか
  - 特に**全体の合計文字数ルールを遵守**しているかが重要
- **ソース整合性**: content_planの情報のみが使用されているか
- **エンタメ性**: 視聴者が最後まで楽しめる内容になっているか
- **文字数適正**: 制限内かつ十分な情報量が確保されているか
- **表現自然さ**: 日本語として自然で読みやすいか

### 重要な注意点
- **レビュー結果を最優先**: 指摘された問題は必ず対応する
- **ソース制限絶対遵守**: content_plan外の情報は一切使用しない
- **改善効果の最大化**: 小さな修正でも大きな効果を狙う
- **一貫性維持**: 修正により全体の統一感が損なわれないよう注意
- **視聴者視点**: 常に視聴者の楽しさと理解しやすさを優先

### 成功指標
- Critical Issues が完全に解決されている
- Major Issues の大部分が改善されている
- エンターテイメント性が大幅に向上している
- ルール遵守率100%を達成
- 視聴者体験が劇的に改善されている
