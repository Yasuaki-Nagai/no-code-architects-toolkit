### 台本修正ルール

#### Critical Issues への対応（最優先）
- **ルール違反**: 即座に修正し、ルール完全遵守を確保
- **ソース逸脱**:
  - content_plan外の情報を除去し、ソース内情報のみに修正
  - 感想やツッコミを入れいている部分は全体文字数範囲内であれば許可
- **構成問題**: サブタイトル配置、形式一貫性などの構造的問題を解決
- **文字数超過**: scene_typeごとのオブジェクトの文字制限、全体文字数制限を厳守するよう調整

#### Major/Minor Issues への対応
- **エンターテイメント性**: より魅力的で親しみやすい表現に改善
- **視認性**: 文節分割や複合語処理を最適化
- **流れ**: 導入→結論の分離や継続視聴を促す構成に調整
- **表現**: 硬い表現をカジュアルで感情豊かな表現に変更
