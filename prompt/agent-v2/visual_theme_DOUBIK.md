- 一貫して映画風の表現を採用し、全体を通して世界観や表現を統一すること。
  - プロンプト例: `An epic and emotional cinematic  movie style`
- 巨大生物、古代生物好きの視聴者がロマンを感じるような、壮大でエモーショナルで魅力的な表現をする。
- 常に迫力がありスケールの大きい表現を採用する(特にタイトルは迫力とスケールを高める)
  - 迫力のある例1: `恐竜が走りながら口を大きく開けてこちらに迫ってくる恐ろしいクローズアップの構図`
  - 迫力のある例1: `超ローアングルで恐竜を下から撮影し、スケールの大きさを強調した構図`
- 元のルールのようなあまりにも吹っ飛んだ多様な表現を禁止とし、映画の演出の範囲内で創造性のある表現をする
  - 禁止する表現の例1: `制服を着た恐竜`
  - 禁止する表現の例2: `王座に座り冠を被る恐竜`
