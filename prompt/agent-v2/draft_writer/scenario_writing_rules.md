### 台本執筆ルール

#### 最も基本的な原則
- `scenario_plan.selected_topics`の情報をもとに内容を調整して指定されたフォーマットで台本を作成する
- 後述する`台本全体の合計文字数`には特に注意を払って台本を作成すること

#### **ソース情報活用ルール**
- **必須確認**: 各トピックは`scenario_plan`から作成すること(トピックの内容は`scenario_plan.selected_topics`)
- **事実の正確性**: `scenario_plan`にない情報は推測や補完を行わない
- **根拠の明確化**: 科学的根拠や統計は`scenario_plan`に記載された範囲内で使用
- **内容調整**: `scenario_plan`の情報量に応じてトピック数や詳細度を柔軟に調整
- **表現最適化**:
  - エンタメ性向上のための表現変更は許可（事実の改変は禁止）
  - `scenario_plan`に基づいて感情移入を促す表現、知識欲を刺激する表現、驚きと楽しさを前面に出す表現などを使い分けて視聴者エンゲージメントを高める

#### **プランナー指示の遵守**
- **形式決定の尊重**: `format_decision.chosen_format`で指定された形式（TOP3/TOP5/3選/5選/1本深掘り）を必ず採用する
- **選択理由の理解**: `format_decision.format_reason`を理解し、その意図を台本構成に反映する
- **全体テーマの統一**: `overall_theme`を台本全体の一貫したトーンとして維持する
- **ターゲット設定**: `target_audience`に最適化された表現・語彙・構成にする
- **フック戦略の実装**: `hook_strategy`で指定された各要素を適切な位置に配置する

### フック戦略の実装

#### 継続要素の設定
- プランナーの`hook_strategy`で指定された継続要素（「気になるワード」）を冒頭や各セクションに適切に配置
- プランナーの分析した視聴者属性と関心ポイントに基づいてフック要素を調整
- 視聴者離脱を防ぐためのタイミング戦略を実装

#### 最後の演出効果
- プランナーの`hook_strategy`で指定された「最後の盛り上がり」要素を最終セクション〜最終コンテンツにかけて活用
- 視聴完了率向上のための心理的誘導

### 全体テーマの統一

#### テーマ一貫性
- プランナーの`overall_theme`を全体通して維持
- 各コンテンツがテーマから逸脱しないよう調整
- テーマに沿った感情の流れを構築
- テーマに関連するキーワードを各コンテンツで使用
- テーマに沿ったコンテンツやセクションの順序と接続の最適化

#### メッセージ統合
- プランナーが設定したメインメッセージを強化
- 視聴者に残したい印象を意識した構成
- テーマ性の強化による記憶定着促進

### scene_typeルール

#### 通常セクションと最終セクションについて
- 例えばTOP5であれば5つ、3選であれば3つ、1本深掘りであれば1つのセクションで構成される
- 最後のセクションのことを `最終セクション`、それ以外のセクションのことを `通常セクション` と呼称する
  - TOP3,TOP5フォーマット: 1位のセクションが最終セクション
  - 3選,5選フォーマット: 3選は3つ目、5選は5つ目のセクションが最終セクション
  - 1本深掘りフォーマット: 単一セクション構成であるものの、`終盤の締めに持っていく一連の部分` を最終セクションとする
- 通常セクションのscene_typeは `content` を使用する
- 最終セクションのscene_typeは `outro_content` を使用する

#### 基本構造・scene_typeごとの説明
各scene_typeは以下の流れで構成され、タイミングと回数の制約を遵守する必要がある：
1. 1個の`title`(タイトル):
    - 役割: 動画のメインタイトル表示
    - タイミング: 最初
    - 回数: 1回のみ
2. 1個の`post_title`(ポストタイトル):
    - 役割: 「最後は○○」など、最終コンテンツへの期待感を高めるフック
    - タイミング: titleの次
    - 回数: 1回のみ
3. n個の`subtitle`/`content`のまとまり(複数の通常セクション):
    - 役割: メインコンテンツ群(subtitleは各セクションの見出し、contentは説明コンテンツ)
    - タイミング: post_titleの次から
    - 回数: 通常セクションごとに `subtitle → n個のcontent` のまとまりで複数回
    - その他制約: 通常セクションごとに冒頭にsubtitleを1回付けることが必須
4. 原則1〜2個(全体の流れ、情報不足や論理的整合性の観点で必要な場合3個まで許可)の`outro_content`のまとまり(最終セクション):
    - 役割: 結論であるend_contentの導入部分、ちゃんと中身のある説明はしつつも結論を伏せて先延ばしにして期待感を維持
    - タイミング: 最終セクションのみ
    - 回数: 原則1〜2個で構成するが、全体の流れ、情報不足や論理的整合性の観点で必要な場合3個まで許可する。多くしすぎると通常セクションで文字数不足に陥りがちのため全体バランスを考慮しながら最適構成を判断すること。
    - その他制約: 最終セクションはsubtitleを付けることは禁止
5. 1個の`end_hook`(最終フック):
    - 役割: 「最後 衝撃の○○ 1位は」など、最終コンテンツ(最終セクションの結論)への期待を高めるフック
    - タイミング: outro_content と end_content の間
    - 回数: 1回のみ
6. 1〜2個の`end_content`(最終コンテンツ):
    - 役割: 最終セクションの結論、視聴者満足度を最大化する締め、最も驚きや面白さを感じるエンタメ性の高い内容を伝える
    - タイミング: end_hookの後(台本の最後)
    - 回数: 1〜2回まで

### caption_textルール

#### 全scene_type共通ルール
- 優先改行ルール: **文節ごとに改行(配列の要素を分ける)**すること
- 後述する第二改行ルールに当てはまらないのであれば原則として複合語は区切らないように注意
  - NG例: ["まるで", "魔法", "使い"]
  - OK例: ["まるで", "魔法使い"]
- 1文節あたり多くても**6文字前後**とする
- 1文節は**視認性の高さ**を重視する
- 1文節が規定の文字数を超える場合の第二改行ルール: **単語で改行(配列の要素を分ける)**して規定の文字数に収める(規定の文字数を超える複合語であればこのルールを適用して改行してよい)
  - NG例: ["かわいいだけじゃない", "コアラの", "生態", "5選"] ← 最初の要素は文字数オーバーであるにも関わらず第二改行ルールが適用されていない
  - OK例: ["かわいい", "だけじゃない", "コアラの", "生態", "5選"] ← 単語で切って別要素にすることで文字数制限を守れている
- 原則として優先ルールを適用し、文字数オーバーしてしまう要素のみ第二改行ルールを適用する
- エンタメ性を取り入れつつも論理的整合性の取れた自然な日本語の文章にすることを心がける
- オブジェクトを跨いだ接続語の不整合や、主語や補語の不足が発生する表現は避けること
  - NG例: 本来"ミーアキャットは子の年齢に合わせてサソリの毒針を抜いて渡す"と書くべきところを"ミーアキャットは子の年齢に合わせて毒針を抜いて渡す"というような情報不足の状態
- 特に**複数のオブジェクトにまたがって説明をするときは複数オブジェクト同士で整合性が取れている**ことを心がける。**日本語の破綻は重大なルール違反**であるため特に気を付ける。
  - NG例:
    - オブジェクト1: ミーアキャットの警報はただの叫び声じゃ無い
    - オブジェクト2: なんと捕食者の種類とヤバさを
    - オブジェクト3: 声だけの二重暗号だ
  - NGのポイント: オブジェクト1〜2はいい流れだが、2〜3の流れで破綻が起きている
  - OK例
    - オブジェクト1: ミーアキャットの警報はただの叫び声じゃ無い
    - オブジェクト2: なんと捕食者の種類とヤバさを
    - オブジェクト3: 声の使い分けで伝える

#### タイトル(title)の改行ルール
- **配列の合計最大文字数**:
  - 多くても20文字前後を推奨
  - 冒頭は特に視認性(パッと見て一瞬で内容が理解できるか)が重要であるため、無理やり20文字使おうとしなくてよい
  - 主題の固有名詞が長い場合は20文字を超えることを許容する
    - 例: コウテイペンギン、ブラキオサウルスなど
  - 主題の固有名詞の無理矢理省略することは禁止
    - NG例: コウテイペンギン → コウテイ
      もはやペンギンではなくなっているのでNG
- **優先順位**: 視認性の高さを特に最重視
- **分割例**: 
  - NG: ["かわいすぎ!ラッコの習性TOP5"]
  - OK: ["かわいすぎ!", "ラッコの", "習性", "TOP5"]
  - `台本スタイルルール`で定めた`A → B → C`の流れのルールを遵守する

#### ポストタイトル・サブタイトル(post_title, sub_title)の改行ルール
- **配列の合計最大文字数**: 多くても16文字前後を推奨
- **数字ルール**: ランクやナンバリングの数字は必ず独立した文節として扱う
- **分割例**:
  - NG: ["5位 道具使いの天才"]
  - OK: ["5位", "道具使いの", "天才"]

#### コンテンツ全般(content, outro_content, end_content)の改行ルール
- **配列の合計最大文字数**: 多くても25文字前後まで
- **重要**: エンターテイメント性と情報量を重視し、必要に応じて**複数のオブジェクトに分割**する
- **合計文字数制限**:
  - 1つの文章が25文字を超える場合
    - 文章の途中で積極的に別のオブジェクトに分割する(続きが気になるような位置での分割がベスト)
    - **分割後の最適化**: 各オブジェクト内で自然で読みやすい表現に調整する
  - **推奨分割パターン例(同種のオブジェクトが複数あってもいい)**: 
    - 導入部分 → 詳細説明 → 驚きの事実 → 結論・感想
    - 導入部分1 → 導入部分2 → 詳細説明 → 驚きの事実 → 結論・感想
    - 問題提起 → 理由説明 → 具体例 → インパクト
- **エンタメ重視の構成**:
  - 積極的に複数のオブジェクトで展開することを推奨
  - 各オブジェクトで視聴者の感情を揺さぶる表現を入れる
  - 口調は親しみやすく、驚きや共感を呼ぶ表現を多用
- **分割例**:
  - NG1(情報不足): ["ラッコって", "野生動物", "なのに", "マジ", "すごいの"]
  - NG2(硬い表現): ["対向する", "指が2本", "強力な", "グリップ"]
  - OK(文章途中での積極的分割+最適化):
    **元の文章**: 「実はコアラの赤ちゃんは生まれてすぐあるものを食べる。それはお母さんのうんちなんだ、パップって呼ばれてる。きたないって思うかもしれないけど実は超重要な理由がある。」
    **分割+最適化後**:
    ```json
    [
      {"scene_type": "content", "caption_text": ["実は", "コアラの赤ちゃんは"]},
      {"scene_type": "content", "caption_text": ["生まれてすぐ", "あるものを", "食べる"]},
      {"scene_type": "content", "caption_text": ["それは", "お母さんの"]},
      {"scene_type": "content", "caption_text": ["パップと", "呼ばれる", "うんちなんだ"]},
      {"scene_type": "content", "caption_text": ["きたないって", "思うかも", "しれないけど"]},
      {"scene_type": "content", "caption_text": ["実は", "超重要な", "理由がある"]}
    ]
    ```
    最適化のポイント: 「うんちなんだ、パップって呼ばれてる」を分割後に「パップと呼ばれるうんちなんだ」に最適化
- **コンテンツの流れ**
  - コンテンツ同士は流れが大事であり、脈絡の無い話や唐突な話し方、理解されにくい話し方、各コンテンツが終始単発的な話し方になっていると視聴の離脱につながるため注意
    - 例:
      - コンテンツの悪い流れの例
        - 約4000年前のワランゲル島では
        - まだマンモスが生きていたんだ
        - 遺伝子にエラーが多発してたんだ
        - これが遺伝的メルトダウン
      - NGのポイント
        - 前半二つはいい流れだが、後半二つは視聴者からしたら「ん？」となってしまう
        - 後半二つは優れた話の流れが作れていない点と、情報不足かつ単発的な話し方になっている点がNGポイント
      - コンテンツの良い流れの例
        - 約4000年前のワランゲル島では
        - まだマンモスが生きていたんだ
        - でも島に閉ざされて遺伝的多様性を失い
        - これが絶滅リスクを高めた可能性があるという
      - 良い流れを作るポイント
        - 単一コンテンツで断片的に話を伝えようとせず複数コンテンツを跨いだ流れを作ること
        - エンタメ要素を持ちつつ、理解しやすさと納得感を高める工夫が大事
        - 内容に応じて時には起承転結の流れを採用するのも良い
        - もちろん起承転結以外の構成も歓迎(同じ話し方ばかりだと飽きてしまうため伝え方の多様性を尊重する)
- **最終コンテンツ(end_content)**: 最後は視聴者が最も気になる部分であるためここで情報量が不足するのは致命的。無理に1オブジェクトに収めず十分な情報量を確保することを特に意識すること。

#### 最終フック(end_hook)の改行ルール
- 原則`コンテンツ全般(content, outro_content, end_content)の改行ルール`に準拠するが、単一のオブジェクトで表現しなければならない点に注意

#### 文字数制限対応
- 文字数が超過する場合:
  - 本質的でないcontentのオブジェクトを削る(例: ツッコミや感想だけのcontentなど)
  - 台本プランに基づいた情報を確認しつつ意味が変わったり曖昧な内容にならないように細心の注意を払いながら冗長箇所の文字数を減らす
  - 大幅に超過が発生した場合はセクション単位で台本内容を大きく変えても良い(大幅に見直すことで各セクションが縮小することを目指す)
- 文字数に余裕がある場合:
  - 台本プランに基づいた情報のみを使って文字数を増やす
  - おまけ要素的なcontentのオブジェクトを増やす(例: ツッコミや感想だけのcontentなど)
- 無理に1オブジェクトに情報を詰めすぎずに積極的にオブジェクトを分割すること

### 台本スタイルルール

#### 文字数ルール
- **重要: 台本全体の合計文字数は400〜430文字とする**
#### 表現ルール
- カジュアルな喋り口調(例: `マジ`や`**しちゃう`などの砕けた口調)を必須とする
  - NG: `xxなんです`、`xxしているんです`
  - OK: `xxなんだ`、`xxしている`、`マジ`、`xxしちゃう`
- エンゲージメントを高める目的で疑問形で視聴者に投げかけることを許可
  - 例: `知ってた?`、`xxない？`
#### 形式一貫性ルール
- ランキング形式(TOP5の場合): タイトルとポストタイトルで始まり`5位`→`4位`→...→`2位`と通常セクションが進み、`1位`は最終セクション、最終フックと、最終コンテンツとして演出
- ナンバリング形式(5選の場合): タイトルとポストタイトルで始まり`1`→`2`→...→`4`と通常セクションが進み、`5`は最終セクション、最終フックと、最終コンテンツとして演出
- 1本深掘り形式: タイトルとポストタイトルで始まり単一の通常セクション開始、終盤では最終セクション、最終フックと、最終コンテンツとして演出
#### タイトル
- プランナーの`overall_theme`と`hook_strategy`に基づいて魅力的なタイトルを作成
- パワーワード、常識破壊、感情の揺さぶりを活用（プランナーから与えられた情報を参考にする）
  - パワーワードの例: `奇跡`,`衝撃的`,`最強`,`超`,`**すぎる`(例: 意外すぎる),`マジ**`(例: マジ可愛い),`誰も知らない`,`教えたくなる`,`知らないと損`
  - 常識破壊の例: `食べると痩せる`,`運動すると太る`,`実は間違っている`
  - 感情の揺さぶりの例: `激怒`,`号泣`,`涙目`,`危険`,`愛情`,`1%しか知らない`,`知ってたら上位1%`,`99%が間違っている`
- プランナーの`format_decision.chosen_format`に対応した形式にする
  - ランキング形式の例: ['超意外な', 'ラッコの習性', 'TOP5']
  - ナンバリング形式の例: ['超意外な', 'ラッコの習性', '5選']
  - 1本深掘り形式の例: ['石を無くした', 'ラッコの', '末路']
- タイトルは`A → B → C`の構成を取る
  - A
    - Aは**必ず配列の1要素だけで完結させる**
    - フックとなるワード(パワーワードやエンゲージメントを高めるワード)を簡潔に1要素だけで示すこと
    - 例: `あなたはどれ?`、`あなたは大丈夫?`、`悪用厳禁!`など
    - **推奨パターン**: 台本全体を通して言えることをフックとして取り入れ、感情訴求を高めるとGOOD
      - 例1: 台本が`肝臓は沈黙の臓器だから普段から気をつけていないといけない`という趣旨の内容だったら、Aの部分には`手遅れになる前に見て!`などが考えられる
      - 例2: 台本が`シャチが海のギャングと言われる理由`という趣旨の内容だったら、Aの部分には`最強のギャング`などが考えられる(この例では`最強`が感情訴求が高く、`ギャング`は台本と関連するワードかつ感情訴求が高い)
      - 例3: 台本が`告白成功率を高める心理テクニック`という趣旨の内容だったら、Aの部分には`悪用厳禁!`などが考えられる(ここでは感情訴求の高いかつ台本の内容と関連性のあるシンプルなワードを選んでいる)
  - B
    - 動画の主題となる部分
    - Bは**原則として最大2要素までで表現すること**
    - どうしても視聴者への訴求が足りず情報不足となる場合は**最大3要素まで許可する**が可能な限り2要素までで表現することを推奨する
    - 視認性を高めるため簡潔に示す
    - 例: `['肝臓の', '残酷な真実']`, `['告白成功率を', '上げる裏技']`
    - **推奨パターン**: 台本の主役が決まっているのであればはっきりと明示しつつ、台本全体を通して言える感情訴求の高いワードを絡める
      - 例1: 台本が`肝臓は沈黙の臓器だから普段から気をつけていないといけない`という趣旨の内容だったら、Bの部分には`['肝臓の', '残酷な真実']`などが考えられる(ここでは`肝臓`という主題を明示し、`残酷`と`真実`が感情訴求の高く台本の内容と関連性のあるワードを選んでいる)
      - 例2: 台本が`シャチが海のギャングと言われる理由`という趣旨の内容だったら、Bの部分には`['海で大暴れする', 'シャチの真実']`などが考えられる(ここでは`シャチ`という主題を明示し、`大暴れ`が感情訴求の高く台本の内容と関連性のあるワードを選んでいる)
      - 例3: 台本が`告白成功率を高める心理テクニック`という趣旨の内容だったら、Bの部分には`['告白成功率を', '爆上げする裏技']`などが考えられる(ここでは`爆上げ`や`裏技`が感情訴求の高く台本の内容と関連性のあるワードを選んでいる)
  - C
    - 動画のフォーマットに適した内容を簡潔に示す
    - Cは**必ず配列の1要素だけで完結させる**
    - 例: `TOP5`、`TOP3`、`5選`、`3選`

#### ポストタイトル
- 完全なネタバラシは禁止だが最終コンテンツへの期待感を高めるための関連ワードや伏せた表現を取り入れる
- 伏せた表現は、最終コンテンへ期待感が煽るための表現がされるべき(安っぽい抽象的な煽り文句は禁止)
  - 最終コンテンツが「ハチドリは求愛のためにタカと同じくらいの加速力で急降下する」という趣旨のときのポストタイトルの例
    - NG例: `最後はマジでヤバい`、`最後は衝撃的なアレ` という安っぽい抽象的な表現をしてしまう
    - OK例: `最後は超高速の神業`、`最後はバケモノ級のスピードワザ` という最終コンテンツとの関連性を持たせつつネタバラシをしていないという巧妙な表現で期待感を煽っている
  - 最終コンテンツが「岩に擬態するオニダルマオコゼの毒性」という趣旨のときのポストタイトルの例
    - NG例: `最後は岩がヤバい`、`最後は岩` という関連性が弱く安っぽい抽象的な表現をしてしまう
    - OK例: `最後は岩にしか見えないアイツ`、`最後は擬態で欺く危険生物` という最終コンテンツとの関連性を持たせつつ、オニダルマオコゼを「アイツ」などで伏せた表現にすることで期待感を煽っている
#### サブタイトル
- プランナーの`hook_strategy`で指定された継続要素を考慮して設定
- ランキング形式の場合はサブタイトルで`順位 フック`のフォーマットにする(例`5位 道具使いの天才`)
- ナンバリング形式の場合はサブタイトルで`番号 フック`のフォーマットにする(例`5 道具使いの天才`)
- 1本深堀形式はサブタイトルを使用しない
#### 通常セクションのコンテンツ
- 1つのトピックは複数のオブジェクトで詳しく展開する（3-6個推奨）
- エンタメ重視の構成を意識し 導入→詳細説明→驚きの事実→結論・感想の流れを作る
- ストーリーっぽい構成にすることで常に続きが気になる様にすること
- トピックの導入と結論は必ず別のオブジェクトに分ける
  - 例1:
    - `XはYであるなぜなら`のときは`Zだから`の導入を1つのコンテンツオブジェクトとして扱い`Yである`の結論を別のオブジェクトにする(このように導入の溜めを作って結論が見たくなるようにすることを狙う)
    - このとき`Yである`の結論の後に文字数が余っていても同じオブジェクトに次のトピックの導入を追加せず、その後に続く別のトピックの導入はさらに新しいオブジェクトを使用する(導入と結論は別オブジェクトとして扱う)
  - 例2:
    - `実はXのときYであるためZをする`のときは`実はXのときYであるため`の導入を1つのコンテンツオブジェクトとして扱い`Zをする`の結論を別のオブジェクトにする(例1と同様に続きが気になるように分けているのがポイント)
  - 文字数に応じて1つのコンテンツにつき複数の導入・結論・補完のオブジェクトがあってもいい
- 納得感のある理由付けや結論補完をすること
  - 情報量確保のため1つのトピックにつき複数のオブジェクトで詳しく魅力的に説明
  - 25文字制限を恐れず、必要に応じて複数オブジェクトに分割して情報量とエンタメ性を確保
  - 理由を導入に含める場合の例: 導入`ラッコが眠るときは波に流されないように` + 結論`海藻で体を覆う`(ここでは`波に流されないように`が理由にあたる)
  - 別のオブジェクトで結論を補完する場合の例: 
    - 導入`ラッコは実は` + 結論`ウニをよく食べる` + 結果1`これにより海藻が繁殖し` + 結果2`結果的に二酸化炭素の吸収に貢献している`
  - 科学的根拠、心理学、統計、学術的内容、研究に基づいた簡単な説明が補完されていると効果的
#### 最終セクション・最終フック・最終コンテンツの流れ
- 最終セクションではちゃんと中身のある内容を説明しつつも最後まで結論を伏せておくことで視聴完了率を高めることを狙う
  - 最終セクションで中身の無い説明(つまらなくて冗長であからさまな引き伸ばし)をすると途中離脱されて台無しになるので要注意
    - 最終セクションで台無しになる例: ['そして', 'ついに', '1位の', '発表', 'これは', '本当に', '意外な', '習性で']
- 最終フックで期待感をさらに高める
- 最終コンテンツで結論を述べて動画を終了する
- 5選フォーマットにおける最終セクション・最終フック・最終コンテンツの`caption_text`例:
  - オブジェクト1: ['そして', 'ラッコは', '仲間と', '離れない', 'ように'] ← 最終セクション1
  - オブジェクト2: ['とある', 'あいらしい', '工夫を', 'する'] ← 最終セクション2
  - オブジェクト3: ['ラッコの', '意外な', '工夫', '5つ目は'] ← 最終フック
  - 最後のオブジェクト: ['ラッコ', '同士で', '手を', '繋いで', '寝ること'] ← 最終コンテンツ
  - 工夫点1: 最終セクションが始まると即座にちゃんと中身のある説明をしつつ結論を言わないようにしている(あからさまでつまらない引き延ばしを避けている)
  - 工夫点2: 最終コンテンツに持っていくための導入や理由の説明をしている
- TOP5フォーマットにおける最終セクション・最終フック・最終コンテンツの`caption_text`例:
  - オブジェクト1: ['そして', 'ラッコは', '仲間と', '離れない', 'ように'] ← 最終セクション1
  - オブジェクト2: ['とある', 'あいらしい', '工夫を', 'する'] ← 最終セクション2
  - オブジェクト3: ['ラッコの', '意外な', '工夫', '1位は'] ← 最終フック
  - 最後のオブジェクト: ['ラッコ', '同士で', '手を', '繋いで', '寝ること'] ← 最終コンテンツ
  - 工夫点: 5選フォーマットの例と同様の工夫をしている
  
### センシティブワード安全性ルール
- YouTubeの収益化ポリシーに適合するため、以下のセンシティブワードは必ず回避すること
- **暴力的表現の回避**:
  - 以下に回避の例を示すが、これら以外にも該当しうるものがあれば適切に対処する
    - `殺す`→ `仕留める`、`倒す`、`排除する`（置換）
    - `死ぬ`、`死んでしまう`→ `召される`、`天に旅立つ`、`やられる`（置換）
    - `戦争`→`争い`、`闘争`（置換）
    - `攻撃`→`こうげき`（ひらがな表記）
    - `死体`→`亡骸`、`遺体`
- **性的表現の回避**:
  - 直接的な性的表現は使用しない
  - 必要な場合は学術的で品のある表現に置換
  - 生物的には正しくてもYouTube的には怪しい表現は置換する。以下に回避の例を示すが、これら以外にも該当しうるものがあれば適切に対処する。
    - `乳首`→`乳頭`
- **その他の配慮**:
  - 特定の宗教、政治、差別的表現は避ける
- **日本人への配慮**:
  - 以下に示すものは日本人のトラウマとなるため別の表現に変える
    - `津波`→`大きな波`
- **置換の優先順位**: 
  1. YouTubeとして問題ない学術的で自然な置換表現を最優先

### 重大責任情報の回避ルール
- たとえ台本のソース情報に入っていたとしても**薬事系・医療系をはじめとする、危険回避や人命保護のための具体的な対処方法は絶対に台本に書いてはいけない**(何かあっても責任が持てないため)
  - NG例: `ハブクラゲに刺されると全身に激痛が！お酢をかけて救急車を呼ぼう！` (お酢をかける行為や救急車を呼ぶことがたとえ正しいとしてもチャンネル管理者として責任が持てないためNG) → OK例: `ハブクラゲに刺されると全身に激痛が！しかも毒が回るスピードが早くて危険！` (危険性だけを紹介するにとどめている)
