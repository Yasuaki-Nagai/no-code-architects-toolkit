# プロンプトエンジニアリングガイド

## パラメータ
###  Frequency Penalty
- default: 0.0
- description: 生成AIの出力における表現の多様性を制御するためのパラメータです。このパラメータは、トークンの出現頻度に基づいてペナルティを与えることで、同じ表現が繰り返し使用されることを防ぐ機能を持っています。正の値を設定した場合、AIは同じフレーズを逐語的に繰り返すことを避け、より多様な表現を使用する傾向が強まります。このパラメータは、特に文章の自然さや表現の多様性が重要な場合に効果的です。例えば、クリエイティブな文章作成や、説明文の生成において、単調な表現の繰り返しを避けたい場合に活用できます。

### Maximum Number of Tokens
- default: 2046
- description: 生成AIが一度の応答で生成できるトークンの最大数を制限するパラメータです。例えば、100に設定すると、応答は最大100トークンまでに制限されます。これは特に長文生成の制御や、APIコストの管理に有用です。ただし、設定値が小さすぎると応答が途中で切れる可能性があるため、タスクに応じて適切な値を設定する必要があります。

### Presence Penalty
- default: 0.0
- description: 生成AIが一度の応答で生成できるトークンの最大数を制限するパラメータです。例えば、100に設定すると、応答は最大100トークンまでに制限されます。これは特に長文生成の制御や、APIコストの管理に有用です。ただし、設定値が小さすぎると応答が途中で切れる可能性があるため、タスクに応じて適切な値を設定する必要があります。

### Sampling Temperature
- default: 0.7
- description: Temperatureは生成AIの出力のランダム性を0から2の間で調整するパラメータです。より決定論的な（同じような）結果が必要な場合は値を下げ、より創造的でバラエティに富んだ結果が欲しい場合は1以上に上げてみましょう。

### Top P
- default: 1.0
- description: 出力トークンの選択における多様性を制御するパラメータです。0.1から1.0の間で設定でき、低い値（例：0.1）では最も可能性の高いトークンのみが選択され、高い値（例：0.9）ではより多様なトークンが選択される可能性が高くなります。例えば、0.1に設定すると、累積確率が0.1に達するまでの最も可能性の高いトークンのみが選択対象となります。
